# 全仓交叉审查计划（15 批 × 3 代理 = 45 审计）

> 触发：v26.11.13.03 启动崩溃（Dart 惰性顶层初始化导致桥注册从未执行）暴露"缺少系统性静态审计"。
> 规则：每批 3 个子代理，分别负责**互不重叠**的维度；主会话交叉比对三方结论，判定真伪后统一修复。
> 纪律：六五原则（层-桥唯一通道 / 桥函数 try/catch+Log / ≤500 行 / UI 热插拔零跨模块 import / 端点多参不缺参 / 零源仓库复用）；子代理只 file_read/file_write/file_edit/ls，不验证不提交。

|---|---|---|---|
| 01 | API 调用与封装匹配（端点声明 path/method/router/参数 vs 封装实际用法） | 结构与命名冲突（同名类遮蔽/惰性顶层/导入路径/死代码） | 字段解析与实测匹配（models 映射 vs API_FIELDS_TRUTH 字段树） |
| 02 | 启动装配链（init→bootloader→core→surface 装配/失败路径） | 播放链（queue/reducer/controller/engine 状态一致性） | 下载链（分块/原子落盘/重试/取消/DB 同步） |
| 03 | 登录会话链（QR/短信/token 续期/恢复/登出） | 多账号与收藏（隔离/镜像/计数/防重锁） | 歌词与缓存键（解析/条数防御/键规范/失效） |

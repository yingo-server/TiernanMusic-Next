# TiernanMusic-Next 26.11.10.02 LTS

## 概述
全新重写首个 LTS 发布。六层五桥架构（init/bootloader/kernel/core/logic/surface，桥接层强制日志留痕），
酷狗原生 API 直连（不依赖第三方网关），Flutter + miuix + Riverpod + Isar。

## Added
- **六层五桥架构**：L1 init / L2 bootloader / L3 kernel / L4 core / L5 logic / L6 surface，跨层仅经 lib/bridges/ 桥文件，桥函数统一 try/catch + Log 留痕，layer_audit CI 强制。
- **酷狗原生 API 直连（三态实测锚点）**：gateway.kugou.com 直连，Android/Web/Register 三签名 + playKey + signParamsKey，纯 Dart MD5/AES-128-CBC/RSA；全部端点返回体经匿名/非VIP/VIP 三态实测并写入 docs/KUGOU_API.md。
- **搜索**：关键词搜索，LRU 缓存接入，data.lists[] 实测结构。
- **歌单**：歌单详情/收藏歌单，specialid/data.songs[] 实测结构。
- **榜单**：官方榜单浏览与播放。
- **播放队列状态机**：纯函数 reducer 队列（顺序/随机/单曲循环），播放源编排本地优先、三态语义错误映射（20028/priv_status）。
- **下载管理**：并发 3、分块进度、断点续传语义、完整性校验。
- **KRC 逐字歌词**：KRC 解密 + 逐字时间轴解析，LRC 回退，三级缓存。
- **QR 登录**：二维码登录状态机 + token 续期 + AES 固定 key/iv 加密。
- **亮暗主题**：miuix 亮暗双主题与动效常量表。
- **热插拔 UI 模块**：SurfaceModule 注册表 + SurfaceRegistry 启动装配，搜索/歌单/播放器/曲库/歌词/设置六模块，模块间零直接 import，增删模块只改注册表一行。
- **完整性校验**：构建期加盐 SHA-512 清单 + Ed25519 签名（gen_manifest.dart），运行期 L1 校验，失败拒绝启动；--bypass-integrity 仅 debug 构建生效。
- **下载管理 UI** 与曲库/历史 Isar 持久化（曲库/歌单/播放历史）。

## Changed

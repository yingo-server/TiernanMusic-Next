# TiernanMusic-Next 26.11.10.1 LTS

## 概述
全新重写首个 LTS 发布。六层五桥架构（init/bootloader/kernel/core/logic/surface，桥接层强制日志留痕），
酷狗原生 API 直连（不依赖第三方网关），Flutter + miuix + Riverpod + Isar。

## 架构
- L4 core：签名引擎（三签名+playKey+signParamsKey，纯Dart MD5）、22端点注册表、KRC歌词解密、
  纯Dart AES-128-CBC + RSA（登录加密）、Isar 数据库（曲库/歌单/历史）、文件存储、LRU缓存+统一键规则
- L5 logic：播放队列状态机（纯函数 reducer）、播放源编排（本地优先/三态语义错误映射）、
  下载管理（并发3/分块进度/断点语义）、歌词（LRC/KRC逐字解析+三级缓存）、账号（二维码登录状态机+token续期）、
  搜索/歌单/榜单（LRU缓存接入）
- L6 surface：热插拔 SurfaceModule 注册表、搜索/歌单/播放器/曲库/歌词/设置六模块、亮暗主题、动效常量表

## 三态实测（匿名/非VIP/VIP）
- play_url 权限判定唯一可信源 = status/priv_status；匿名 20028；VIP 曲非 VIP 号 priv_status=0
- 全部端点返回体经实测校验并写入文档（搜索 data.lists[]、歌单 specialid/data.songs[] 等修正）

## 质量门禁
- layer_audit 跨层审计全绿；MD5 四向量 PASS；本地 analyze 非 SDK 缺失噪音 error = 0
- CI：analyze/test/layer_audit 报错不妥协汇总判定 + split-per-abi 三架构构建
